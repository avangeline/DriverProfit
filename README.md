# DriverProfit (แอปบันทึกค่ารอบและต้นทุนน้ำมัน Grab)

แอปพลิเคชัน Native Android พัฒนาด้วย **Kotlin + Jetpack Compose + Material 3 + Room Database** ออกแบบมาสำหรับคนขับ Grab โดยเฉพาะ เพื่อบันทึกค่ารอบและคำนวณต้นทุนน้ำมันสุทธิได้อย่างรวดเร็ว (Speed-first) ภายใน 3–5 วินาที พร้อมแก้ปัญหาตัวเลขหน้าปัดไม่คำนวณเวลาที่รถจอดนิ่ง/ติดไฟแดง (Engine Idling)

---

## 🚀 ฟีเจอร์หลัก (Key Features)

1. **บันทึกรอบวิ่งด่วนพิเศษ (Ultra-Fast 3-5 Sec Entry):**
   - กรอกเพียง **ค่ารอบ** และ **ระยะทาง** เป็นช่องบังคับ
   - หน้าปัดรถ (km/L) และเวลารอบวิ่ง (นาที) รองรับการแตะแก้ไขและจำค่าล่าสุดอัตโนมัติ
   - ปุ่มลัดทิป `[+1]`, `[+5]`, `[+10]`, `[+20]` พร้อมปุ่ม `[ล้าง]` ทันทีหากเผลอกด
   - ระบบคำนวณทิปอัตโนมัติจากเงินสด `[💵 เงินสด]` (กรณีลูกค้าจ่ายเกิน เช่น แอปให้เก็บ ฿85 ลูกค้าจ่ายแบงก์ร้อย ฿100 -> คำนวณเป็นทิป ฿15 ให้ทันที)
   - **ระบบเพิ่มทิปย้อนหลัง (In-App Tip):** แตะที่ปุ่ม `[+ ทิป]` บนการ์ดรอบวิ่ง เพื่อเพิ่มทิปที่ลูกค้าเพิ่งกดให้ผ่านแอป Grab ย้อนหลังได้ทันที โดยระบบจะอัปเดตกำไรสุทธิและยอดสรุปของวันให้อัตโนมัติ
   - แถบ Live Calculation พรีวิวค่าน้ำมันและกำไรสุทธิสดๆ ขณะพิมพ์
2. **ระบบคิดต้นทุนจริงผสานเวลารถติด (Dash km/L + Idling Engine):**
   - ดึงค่าน้ำมันขณะรถวิ่งจากหน้าปัดรถ: $\text{ระยะทาง} \div \text{หน้าปัด (km/L)}$
   - ประเมินเวลาที่รถจอดนิ่ง/ติดไฟแดง (Idling Time) จากเวลารวมของรอบเทียบกับระยะทาง
   - คำนวณค่าน้ำมันเดินเบาตอนรถติดตามอัตราของเครื่องยนต์ (L/ชม.)
   - แสดงผล **อัตราสิ้นเปลืองที่แท้จริง (Effective km/L)** และต้นทุนจริง ไม่หลอกตัวเอง
3. **จัดการราคาน้ำมันประจำวัน (Daily Fuel Price Banner):**
   - แถบแสดงราคาน้ำมันวันนี้บนหน้าหลัก แตะเพื่อเปลี่ยนราคาน้ำมันประจำวันได้ตลอดเวลา
   - บันทึก Snapshot ราคาน้ำมันลงในแต่ละรอบเพื่อรักษาความถูกต้องของประวัติย้อนหลัง
4. **จัดการรุ่นรถ (Vehicle Profiles):**
   - เลือกรุ่นรถประจำ (เช่น Honda Wave 110i, PCX 160, Eco Car 1.2L)
   - เพิ่มรุ่นรถใหม่ พร้อมกำหนดอัตรากินน้ำมันมาตรฐานและอัตรา Idling
5. **ส่งออกรายงานเป็น CSV (Excel Compatible):**
   - ปุ่ม Export ข้อมูลรอบวิ่งของวันเป็นไฟล์ `.csv` พร้อม UTF-8 BOM
   - เปิดใน Microsoft Excel หรือ Numbers ภาษาไทยไม่เพี้ยน พร้อมแชร์เข้า LINE / Google Drive ได้ทันที

---

## 🛠️ สถาปัตยกรรมระบบ (Architecture)

- **Presentation:** Jetpack Compose, Material 3, ViewModel (`DashboardViewModel`)
- **Domain:** Use Cases (`CalculateTripUseCase`, `ExportTripsToCsvUseCase`), Models (`DailySummary`, `TripCalculationResult`)
- **Data:** Repository Pattern (`TripRepository`), Room Database (`AppDatabase`, `TripDao`, `VehicleDao`, `DailyFuelDao`)

## 📱 วิธีเปิดโปรเจกต์ใน Android Studio

1. เปิดโปรแกรม **Android Studio**
2. เลือก **File -> Open...** แล้วเลือกโฟลเดอร์:
   ```
   /Users/Dome/DriverProfit
   ```
3. รอให้ Android Studio ทำการ Sync Gradle ให้เสร็จสมบูรณ์
4. เสียบสายโทรศัพท์ Android (เปิด USB Debugging) หรือเปิด Android Emulator
5. กดปุ่ม **Run (▶)** เพื่อติดตั้งและเปิดใช้งานแอปบนมือถือได้ทันที
